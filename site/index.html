Know where your text goes

No SpeedProof cloud. No mystery middleman.

The Mac app sends eligible text directly to OpenAI using the API key you provide. The online proofreader relays only the submitted text through a serverless SpeedProof endpoint so the service key stays private; SpeedProof does not store that text.

Install the preview

On your Mac in three steps.

SpeedProof is currently an open-source preview build. It is ad-hoc signed and does not yet have a Developer ID signature or Apple notarization.

  1. 1

    Download and unzip

    Move SpeedProof.app to your Applications folder.

  2. 2

    Open it deliberately

    Control-click the app and choose Open. If macOS still blocks it, use Privacy & Security → Open Anyway.

  3. 3

    Add your API key

    Open Settings, add your OpenAI API key, then allow Accessibility for paste-back shortcuts.

Good to know

Before you switch it on.

Why does SpeedProof need Accessibility access?

Accessibility lets the global shortcuts capture your selected text and return the finished version to supported editable fields. Clipboard-only processing still works without paste-back.

Do I need an OpenAI subscription?

You need an OpenAI API key with API billing enabled. A ChatGPT subscription does not automatically include API usage.

Is it safe for confidential text?

Do not treat the safeguards as a complete data-loss-prevention system. Both the Mac app and online proofreader send eligible text to OpenAI, so avoid processing anything you are not comfortable sharing with that service.

Can I inspect the source?

Yes. SpeedProof is released under the MIT License and the full Objective-C/AppKit source is available on GitHub.
